Sistema Académico y de Prelaciones en Prolog

Este repositorio contiene dos programas escritos en Prolog que modelan una pequeña base de datos académica y el sistema de prelaciones de un conjunto de materias.

¿Cómo usar?

Para consultar estos programas en Prolog, sigue estos pasos:

1.  Abre la consola de Prolog. con swipl
2.  Carga el archivo deseado usando `[academico].` o `[prelaciones].`
3.  Ingresa tus consultas.

Ejemplo para usar:

prelacion_total(ci2525, ci3661).
y debe dar: true

cursando_sin_nota(elena, ci3725).
y debe dar: true
